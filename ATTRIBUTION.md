## Sources of the factual claims

Every number in `references/official-spec.md` and every prompting rule in `references/prompt-anatomy.md` traces back to public OpenAI documentation:

- OpenAI, *Introducing ChatGPT Images 2.5*, 8 September 2026
- OpenAI API documentation, image generation guide
- OpenAI API model pages for `gpt-image-2` and `gpt-image-2.5-flare`
- OpenAI cookbook, *GPT Image Generation Models Prompting Guide*
